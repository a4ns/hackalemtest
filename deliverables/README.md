## Точная команда повторного рендера

```bash
cd video
npx --yes hyperframes@0.8.143 browser ensure      # один раз: Chrome Headless Shell
npm run check                                     # lint + runtime + layout + motion + contrast
npm run render:final                              # = npx hyperframes@0.8.143 render --quality delivery --output renders/hackalem-intro.mp4  (≈ 25 мин на 4 ядрах, программный WebGL)
npm run render:silent                             # версия без звука
python3 scripts/qc.py renders/hackalem-intro.mp4 renders/hackalem-intro-silent.mp4
```

Звук пересобирается отдельно и детерминированно: `npm run cues && npm run audio` (нужны Python 3, numpy, scipy, soundfile, pedalboard).

**Итог проверки архива:** `hackalem-ai-intro-project.zip` распакован в другую папку, там выполнены `npm run check` (ошибок нет; одно предупреждение линтера `duplicate_media_discovery_risk` — знак подключён двумя `<img>` намеренно: в углу и в лок-апе) и `npm run render:final` (≈ 25 мин). Получившийся MP4 **побитово идентичен** поставляемому (`cmp` — файлы совпали; MD5 видеопотока `3df03315ac5c13106e76e186f21ce929`, MD5 звукового потока `3ade12de130fc185146506145ed9ded4`).

## Что нужно проверить человеку
- **Видео не просматривалось в реальном темпе, звук не прослушивался** (в среде нет воспроизведения). Картинка проверена по сериям кадров и измерениям готового файла, звук — измерениями; независимые рецензенты тоже видели только кадры и цифры.
- Особенно стоит посмотреть и послушать: плавность разлёта кубов (размытие движения — 10–16 суб-кадров), ощущение удара на 8.90 с и «вдоха» перед ним (≈ 0.2 с почти тишины — осознанный приём), баланс и тембры на реальных колонках и на телефоне, не звучат ли стеклянные «лесенки» тиков слишком «игрово».
- Для строгой оценки: три раунда независимых рецензентов-субагентов дали 6.0–7.0 из 10 по шкале «премиальный агентский ролик» (подробности и что осталось — `05_qc.md`). Я не заявляю 9.5/10: это оценка, которую должен подтвердить человек.
- Угловой мини-лок-ап и строка в лок-апе на экране телефона мелкие; ключевое (слова, знак, заголовок) крупное.
- Если слово «ИИ-АГЕНТ» нежелательно — оно меняется одной строкой в `config/cues.json` (`text.agent`; буквы — в `src/glyphs.js`).
