# 02 · Диагноз v1 и концепция v2 «Сборка»

## Что было не так в v1 (оценка заказчика: 5.5 / 10)

Заказчик не расписал замечания, поэтому причины искались самостоятельно: пять независимых критиков-субагентов (арт-директор, режиссёр монтажа, саунд-дизайнер, стратег бренда, скептичный зритель) смотрели кадры и измерения v1. Сошлись на одном и том же:

| Симптом | Причина |
|---|---|
| «Плоско» | Canvas 2D: плиты без света, объёма, материалов, отражений, глубины. |
| «Не бренд» | Сайт — тёмная сцена с лучом света; v1 — большая **светлая синяя плита**: инверсия. |
| «Рвётся» | Стена из тысяч мелких клеток + искры + HUD: много мелких событий вместо одного большого. |
| Слабая кульминация | Белая вспышка и «квадратная волна» без света, масштаба и музыкального удара; пик в 9.6 с из 15. |
| Бренд коротко | Лок-ап стоял ≈ 2.5 с, строка 40 px. |
| Звук | 72 % энергии ниже 150 Hz (98-й перцентиль среди 43 реальных треков), 8-битные тембры, нет реверберации — «басит, тонко, игрушечно». На ноутбучном динамике −3.2 LU. |

Вывод: это не правка, а перестройка. Тонкая настройка v1 дала бы 6, не 9.

## Три направления, из которых выбрано одно

1. **«Сборка» (выбрано).** Один пул из 173 глянцевых стеклянных кубов (ровно столько клеток в знаке) складывается в слова ИДЕЯ → КОМАНДА → ИИ-АГЕНТ и, наконец, в знак; свет вырывается через вырезанную фигуру. Один мир, один объект, одна непрерывная камера. Идея — «из одних и тех же кубиков»: слова не отдельные плашки, а этапы одной сборки.
2. «Агент за работой» — экран с интерфейсом, в котором агент пишет код. Нагляднее по смыслу, но превращает бренд в скринкаст, а честно показать «агентность» без реальных интерфейсов нельзя.
3. «Луч» — только свет и тень, силуэты в кресле, как hero сайта. Красивее всего в статике, но слабее по сюжету и по читаемости на телефоне.

Выбор «Сборки»: она переносит в 3D главное свойство знака (16×16 «пикселей»), даёт естественные три слова, осмысленную кульминацию (знак собран → удар → свет через вырез) и позволяет сделать картинку «дорогой» (материал, свет, глубина резкости, бликующие кромки), не выходя за возможности рендера на CPU.

## Что изменилось по существу

* **Мир тёмный**, `#060B16`; синий `#009AF0` — только эмиссия (свет), на логотипе — награда. Белый — шрифт и вспышка.
* **Один герой-объект.** Кадр 0: наклонённый светящийся куб на фоне поля тёмных стеклянных кубов — уже брендирован (оригинальный `logo.svg` в углу, строка-подпись).
* **Кульминация в 8.9 с**, лок-ап — 4.7 с (из них 3.3 с — держащаяся композиция); слова держатся по 1.1–1.2 с.
* **Крупная типографика**: заголовок «HackAlem AI» 188 px (Manrope 800), строка ≈ 59 px (JetBrains Mono, по ширине заголовка), слова из кубов — буквы высотой 250–380 px. Третье слово — «ИИ-АГЕНТ» (по итогам критики: «АГЕНТ» без контекста читается как «шпион»).
* **Нет HUD, нет стоящих квадратов, нет искр.** Движение — крупные перелёты кубов с motion-blur по 6–12 суб-кадрам.
* **Звук**: срединный хук на кадре 0, реальные CC0-семплы под синтезом, настоящая реверберация, баланс по октавам приведён к медиане реальной музыки.
