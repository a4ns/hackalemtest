# 04 · Звук: спецификация и карта сигналов

**Правило, общее с картинкой:** детальность звука растёт вместе с «разрешением» кадра. Акт I — 2–4-битные «лоуфай» тики (низкая частота дискретизации, узкая полоса); акт II — 8-бит, ритм появляется; акт III — полный бас и райзер; обратный отсчёт — звук «теряет разрешение» (быстро падающие по частоте/полосе тоны); кульминация — первое полноразрядное, широкое, стерео-звучание; финал — чистый pad и нежные «пиксельные» тики.

Тональность: ре (D). Акты I–III — ре-минор / пентатоника (ф без диеза, F♮). **На кульминации — переход в ре-мажор (F♯) — смысловой «выдох».**
Темп 150 BPM: доля = 0.4 с, шестнадцатая = 0.1 с = 3 кадра. Все времена берутся из `config/cues.json` (`T.*`) — звук строится от тех же чисел, что и картинка, при изменении тайминга звук пересобирается скриптом.

Только оригинальный синтез (Python/numpy), без сэмплов и чужих материалов.

## Карта сигналов

| t, с | Картинка | Звук |
|---|---|---|
| 0.000 | Кадр 0: синяя плита, искра, трещина | **Акцент №1.** Саб D1 (≈37 Гц) 0.35 с + сухой электрический «треск»/тик (2-бит, 4 кГц) 0.2 с. Начинается ровно на семпле 0 (микро-фейд 2 мс, без щелчка) |
| 0.00–0.40 | Трещина растёт | Растущий 2-бит прямоугольник 200→900 Гц |
| 0.40 | n=2, «ИДЕЯ» открывается (блоки 120 px) | Удар + аккорд-стаб D/A (4-бит) |
| 0.60, 0.80, 1.00, 1.20 | Блоки 60→30→15→чёткое | 4 тика-ступени: растёт высота (D4, F4, A4, D5) **и** разрядность/частота дискретизации (2→3→4→6 бит; 4→8→12→24 кГц). На 1.20 — чистый «щелчок-колокольчик» D5 в полном разрешении |
| 1.2–2.0 | «ИДЕЯ» держится, клетки мерцают поодиночке | Саб-педаль D1 тихо; редкие случайные «пиксельные» блипы (псевдослучайно, но детерминированно: seed), панорама случайная, очень тихо |

| 2.00–2.40 | Закрывающий фронт слева направо | Фильтрованный шум L→R + три «пинга» рождения искр (2.10, 2.20, 2.30: A5, C6, E6) |
| 2.40–3.20 | Три искры прыгают (8 шагов по 0.1) | 8 ступенчатых блипов арпеджио D F A C D F A C (6-бит), панорама попеременно, нарастающий фильтр, райзер к 3.20 |

| 3.20–4.00 | Три резака (КО →, МАН ↓, ДА ←) | Три слоя «скан»-тона: L (растущий), центр (падающий), R (падающий); хэт на 16-х |
| 4.00, 4.40, 4.80 | Все клетки синхронны | Бочка «четыре на пол» ложится в сетку (4.0 — с хлопком), бас D1/F1 |
| 4.80–5.20 | «Молния» закрывает слово | Реверс-снейр + 4 ступенчатых тика вниз |
| 5.20–5.60 | Искры стыкуются в углу | 3 пилюли-плака (D4, F4, A4) приземляются к 5.60 аккордом |
| 5.60–7.10 | Писарь режет «АГЕНТ» (ускоряется) | Быстрая арпа 16-ми, ускоряющийся хэт; акценты на завершении букв 6.00, 6.36, 6.66, 6.90, 7.10 — восходящие колокольчики D4, F4, A4, C5, D5 |
| 7.20–8.00 | Скан-линия делит клетки (8 шагов) | Райзер (пила+шум 200→8000 Гц), 8 ступенчатых ярких кликов с повышением высоты |
| 8.00, 8.40, 8.80, 9.00, 9.10 | Пакеты от команды к агенту | Ускоряющийся клэп/снейр: на этих временах + ролл 16-ми 9.00–9.20; пик райзера к 9.20 |
| 9.20–9.50 | Обратный отсчёт 256→64→16→4→1 | **Музыка вырезается** (всё, кроме отсчёта). 4 падающих тона (A5→A4→A3→A2) на 9.20, 9.30, 9.40, 9.50, полоса сужается (звук теряет разрешение) |
| 9.50–9.60 | Белая искра в центре — зеркало кадра 0 | Почти тишина: одиночный высокий пинг + обратный свелл («вдох») до 9.60 |
| **9.600** | **Удар (кадр 288)** | **ГЛАВНЫЙ УДАР.** Саб-бум D1 со скольжением 80→36 Гц (1.2 с), большая бочка, широкий шум, тарелка-крэш, аккорд Dmaj9 (D2 A2 E3 F♯3 A3 C♯4 E4), суперпила, широкое стерео, длинный хвост. Первое «24-битное» звучание |
| 9.60–10.10 | Квадратная волна (8 колец по 2 кадра) | 8 металлических кликов с ростом высоты (по аккорду, 9.600, 9.667, …, 10.067), расширяющаяся стереобаза |
| 10.10–10.50 | Знак сияет | Тянущийся pad, тихие «искры», хвост реверберации |

| 10.95–11.70 | Вордмарк «печатается» клетками | Каскад гранулярных тиков слева направо (≈400 тиков/с, панорама L→R, ноты из D-мажорной пентатоники); на 11.70 — колокольчик D6 |
| 11.80–12.10 | Линия вытягивается | Тонкий восходящий свип в 3 ступени |
| 11.90–12.70 | Строка печатается (1 символ/кадр) | Тихие «клавиши»-тики (по одному на кадр) |

| 14.00 | Последний тик: пульс света в силуэте | Мягкий низкий пульс (саб D1, 50 мс) + воздушный свелл |
| 14.0–15.0 | Статика | Хвост реверберации, плавное затухание до тишины к 15.00 (без обрыва) |

## Технические требования
- 48 кГц, стерео, 24-бит WAV (`assets/audio/hackalem-intro-mix.wav`), длина ровно 15.000 с (720 000 семплов).
- Громкость ≈ −14 LUFS integrated, true peak ≤ −1.0 dBTP, без клиппинга (мягкий лимитер на мастере), без щелчков на границах событий (микро-фейды), начало и конец — без разрывов.
- Источники: только собственный синтез (numpy), фиксированные seed → результат воспроизводим бит-в-бит.
