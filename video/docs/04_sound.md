# 04 · Звук v2

> **Честно: звук не слушался.** В среде нет воспроизведения; всё ниже — проект и измерения. Измерения не заменяют ухо: проверьте баланс на реальных колонках и телефоне.

Файл `audio/build_audio.py` строит `assets/audio/hackalem-intro-mix.wav` (48 кГц, стерео, 24 бит, ровно 720 000 семплов). Код — numpy-синтез (порт осцилляторов v1 в `audio/dsp.py`) + эффекты Spotify `pedalboard` (Freeverb-реверберация, эквалайзер, компрессор) + семь CC0-семплов Kenney под синтезом. Времена берутся из `config/cues.json` и `config/events.json` (моменты посадки кубов выгружает `scripts/build-events.mjs` из той же хореографии, что рисует картинку).

## Что было не так в v1 и что сделано

| v1 (измерения `eval_audio.py` по 43 реальным отрывкам) | v2 |
|---|---|
| 72.5 % энергии ниже 150 Hz (98-й перцентиль), на ноутбучном динамике −3.2 LU | **20.5 %** (40-й перцентиль, медиана реальной музыки 28 %); ноутбук **−0.7 LU**, телефон **−1.6 LU** |
| 8-битные тембры, нет реверберации | стеклянные FM-колокола, суперпилы, реальная реверберация (комната + зал), реальные CC0-семплы |
| Октавы: 63 Hz +5.8 дБ выше медианы, 250–2000 Hz на 3–4.5 дБ ниже | октавные полосы 125 Hz–2 кГц в пределах **±2 дБ** от медианы реальной музыки (63 Hz −5.0 — заметно меньше саба, чем у типичной музыки, 4 кГц −2.7) |
| Центроид 390 Hz (глухо) | 0.87 кГц |
| Хлопок первого удара «в никуда», 8-битный хук | Хук на кадре 0: колокольчик D5 + CC0-динг (подстроен под D5) + срединный удар тела 96–210 Hz |

Цель по доле баса — не «как можно меньше»: первая итерация v2 дала 5.6 % и звучала бы «картонно», вторая — 26 %; затем настраивалась динамика (в финале 20.5 % — партия сборки намеренно тише, а звук после удара и в лок-апе держится в среднем регистре).

## Измерения (WAV; `eval_audio.py`)

| Метрика | Значение |
|---|---|
| Громкость | WAV −14.5 / MP4 −14.7 LUFS integrated, LRA 5.7–5.8 LU; моментная: сборка −16…−19, вдох −24, **удар −10 LUFS** |
| True peak WAV / после AAC 192k в MP4 | −2.4 dBTP / −2.0 dBTP (рендерер не занижает дорожку: потолок подобран цикл-проверкой AAC; −0.2 дБ — потери кодека) |
| Баланс | наклон 125 Hz–8 кГц −2.1 дБ/окт; доля 2–8 кГц 4.6 %; центроид 0.87 кГц |
| Моно | потеря при сведении в моно ≥ −2.0 дБ; корреляция баса 0.97 (бас в центре) |
| Щелчки/клиппинг | клиппинг 0, края файла ровно ноль; единственный резкий шаг — намеренный фронт удара на 8.400 |

ML-«слушатели» (Audiobox, CLAP, AST) на финальной дорожке: PQ 7.8 (v1: 8.2); CLAP: ближайшее описание — «clean premium tech logo sting» (0.67; v1: «modern electronic music with punchy bass» 0.91), **но «8-bit chiptune video game music» получил 0.30 (v1: 0.06)** — стеклянные «лесенки» тиков местами читаются как игровые (то же заметили два рецензента-саунд-дизайнера); AST: шум, статика, дисторшн ≤ 0.003. Это **детекторы грубых поломок, а не оценка вкуса** (на масштабе 8.0 vs 9.5 они не различают; на «ушах» заказчика они поставили v1 8.2 при его оценке 5.5). Используйте их как «не сломалось», а не как цель.

## Что вынесено из независимой критики звука (по измерениям)

Принято: арпеджио реже и темнее; **вдох — настоящий вакуум** (дуется и хвост реверберации: 8.7–8.83 с = −35 dBFS RMS, 8.83–8.9 с = −56 dBFS, потом удар −10 dBFS; в первой версии вдох проседал всего на 1 LU); ступени слоёв удара и плавные фронты (2–4 мс); тоника и колокол при сборе заголовка; узкие хвосты и центральные колокола (моно-совместимость); ступенчатый рост уровня по словам (−7.5 → −3.5 дБ до удара); тики со «случайным» ±12 мс разбросом вместо жёсткой сетки; хук тише на 9 дБ относительно первой версии. Отклонено: перенос пика хука с t = 0 на 40–60 мс (хук нужен именно на первом кадре — файл начинается с нуля, первые 2 мс — fade-in).

## Как править
Времена — `config/cues.json` → `npm run cues`; партитура — `audio/build_audio.py` (аккорды `CHORDS`, уровни `gain=`, общий сдвиг доударной части `PRE_DB`); без семплов (чисто синтез): `HK_NO_SAMPLES=1 npm run audio`. Пересборка детерминирована при одинаковых numpy/pedalboard.
